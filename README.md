# Парсер Avito — «калоприемники»

Автоматический мониторинг новых объявлений по запросу **«калоприемники»** по всей
России. Парсер каждые ~40 секунд проверяет поисковую выдачу Avito (новые сверху),
применяет фильтры и сразу шлёт уведомление в **VK** (основной канал) и/или
**Telegram** — со ссылкой, фото, ценой и описанием.

В основе — проверенный и активно поддерживаемый проект
[**Duff89/parser_avito**](https://github.com/Duff89/parser_avito). Этот репозиторий
не дублирует его код, а содержит **готовую конфигурацию и инструкции** под конкретную
задачу: мы собираем Docker-образ парсера из его исходников (закреплён на версии
`v3.2.15`), а здесь храним только настройки.

> Почему так: обход анти-бота Avito — сложная и постоянно меняющаяся задача. Намного
> надёжнее использовать готовый поддерживаемый образ и обновлять его одной командой,
> чем писать и чинить собственный парсер после каждого обновления Avito.

---

## Схема работы

```
VPS (24/7)
  └── Docker: parser_avito:v3.2.15 (сборка из исходников Duff89/parser_avito)
        ├── config.toml ........ ссылка, фильтры, токены, прокси
        ├── мобильный прокси ... обход банов по IP (смена IP при блокировке)
        └── уведомления ........ VK (основной) + Telegram (опционально)
```

Каждый цикл (~40 сек):
1. Заходит по ссылке `https://www.avito.ru/all?q=калоприемники&s=104` через прокси.
2. Берёт свежие объявления (сортировка «сначала новые»).
3. Отбрасывает уже виденные (дедупликация по локальной базе `database.db`).
4. Применяет фильтры (слова, цена, гео, резерв и т.д.).
5. По подходящим — шлёт уведомление в VK/Telegram.

## Быстрый старт на VPS

Подойдёт любой дешёвый VPS на Linux (Ubuntu/Debian) с Docker.

```bash
# 1. Установить Docker (если ещё нет)
curl -fsSL https://get.docker.com | sh

# 2. Склонировать репозиторий
git clone https://github.com/StopIllusionist/parser.git
cd parser

# 3. Подготовить файлы (создаст config.toml, database.db, result/)
make setup        # или: ./setup.sh

# 4. Заполнить настройки (токен VK, прокси, цены и т.д.)
nano config.toml

# 5. Запустить в фоне 24/7
make run          # или: docker compose up -d

# 6. Смотреть логи
make logs
```

Полезные команды (`Makefile`):

| Команда        | Что делает                                            |
|----------------|-------------------------------------------------------|
| `make setup`   | Создаёт `config.toml`, `database.db`, `result/`       |
| `make run`     | Запуск контейнера в фоне                               |
| `make logs`    | Логи в реальном времени                                |
| `make restart` | Перезапуск (например, после правки `config.toml`)      |
| `make stop`    | Остановить и удалить контейнер                          |
| `make update`  | Пересобрать образ из исходников и перезапустить |
| `make ps`      | Статус контейнера                                      |

## Настройка `config.toml`

Все параметры с комментариями — в [`config.example.toml`](config.example.toml).
Скопируйте его в `config.toml` (это делает `make setup`) и заполните.

### Поисковая ссылка

```toml
urls = ["https://www.avito.ru/all?q=калоприемники&s=104"]
count = 1   # 1 = только первая страница (самые новые)
```

`s=104` — сортировка «по дате: сначала новые». Можно добавить несколько ссылок
(например, отдельный регион или другой запрос) — каждая в кавычках через запятую.

### Частота проверки

```toml
pause_general = 40        # пауза между циклами, сек (задача: 35–50)
pause_between_links = 5   # пауза между ссылками внутри цикла
```

> Не ставьте слишком маленькую паузу — это повышает риск бана. 35–50 сек — разумный
> баланс скорость/стабильность для нишевой темы.

### Фильтры

```toml
keys_word_white_list = ["калоприемник", "калоприёмник"]   # пройдёт, только если есть слово
keys_word_black_list = ["куплю", "опт", "оптом", "магазин"] # отбросить, если есть слово
seller_black_list = []     # чёрный список продавцов по sellerId
min_price = 0
max_price = 999999999
geo = ""                   # пусто = вся Россия
max_age = 0                # 0 = без фильтра по времени (дедуп по базе)
ignore_reserv = true       # игнорировать «в резерве»
ignore_promotion = false   # игнорировать платно поднятые
```

**Важные ограничения парсера (чего нет «из коробки»):**
- **Фильтра «только частные лица» нет.** Есть только чёрный список конкретных
  продавцов (`seller_black_list`). Магазины/перекупов можно частично отсекать
  чёрным списком слов (`опт`, `оптом`, `магазин` и т.п.).
- **Фильтра «только с фото» нет.**

### Уведомления VK (основной канал)

Проверенный способ (см. также
[docs/NOTIFICATIONS.md](https://github.com/Duff89/parser_avito/blob/master/docs/NOTIFICATIONS.md)):

1. Создайте сообщество ВК → https://vk.com/groups?w=groups_create_new
2. В сообществе: **Управление → Дополнительно → Работа с API**.
3. Создайте **ключ** с правами: сообщения от имени сообщества + доступ к фото.
4. Вставьте ключ в `vk_token`.
5. В `vk_user_id` укажите **свой числовой id** (из https://id.vk.com/account/#/personal
   или из `vk.com/id1234567` → `1234567`). Нужны цифры, не username.
6. Напишите своему сообществу любое сообщение в ЛС и **разрешите** ему писать вам.

```toml
vk_token = "vk1.a...."
vk_user_id = ["1234567"]
```

### Уведомления Telegram (опционально)

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получите **token**.
2. Начните чат с ботом. Узнайте свой **chat_id** через [@userinfobot](https://t.me/userinfobot).

```toml
tg_token = "123456:ABC..."
tg_chat_id = ["123456789"]
```

### Прокси (рекомендуется мобильный)

Чтобы Avito не банил, используйте мобильный прокси (РФ). Формат — без `http://`:

```toml
proxy_string = "login:password@1.2.3.4:8000"
proxy_change_url = "https://changeip.mobileproxy.space/?..."  # ссылка смены IP (опц.)
```

При бане парсер дёрнет `proxy_change_url`, чтобы сменить IP. Подробнее об обходе
блокировок (мобильный прокси, сервис cookies spfa.ru и т.д.) —
[docs/ANTIBLOCK.md](https://github.com/Duff89/parser_avito/blob/master/docs/ANTIBLOCK.md).

## Обновление парсера

После обновлений Avito может понадобиться свежая версия парсера. Поменяйте тег
версии в `docker-compose.yml` (строка `context: ...#v3.2.15`) на нужный из
[релизов](https://github.com/Duff89/parser_avito/releases), затем:

```bash
make update      # docker compose build --pull && docker compose up -d
```
